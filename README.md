# 教师教研抽签工具

一个面向教研现场的抽签网页工具，适合大屏投影使用。纯静态页面，无需安装，双击 `index.html` 即可运行。

## 功能

- **A / B 两组名单**：可手动编辑，或上传 Excel（`.xlsx` / `.xls`）、`.txt`、`.csv` 文件。
- **自定义抽取人数**：主界面底部直接输入每次每组抽取几人，两组数量均等。
- **抽中不重复**：抽中的人本轮不再参与；【重置】一键恢复全部名单。
- **滚动 + 音效 + 高亮**：开始抽签名单滚动（带音效），停止后定格并高亮选中人员。
- **简洁商务风**：大字号、白底蓝调，适合现场投影。

## 使用

1. 双击打开 `index.html`（或访问部署好的网页地址）。
2. 点击右上角「⚙ 名单设置」上传 / 修改 A、B 两组名单。
3. 在底部输入每组抽取人数，点击「开始抽签」→「停止抽签」。
4. 一轮结束后点击「重置」开始新一轮。

> 快捷键：空格 = 开始/停止，Esc = 关闭设置面板。
